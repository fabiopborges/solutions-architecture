# Roteiro de skills

A lista completa das atividades de um arquiteto de soluções que este OS cobre. Cada uma virou um agente com uma skill própria (Camada 6). As 14 originais foram conquistadas uma de cada vez, seguindo sempre a mesma pergunta: como o time já faz isso na mão hoje. Duas skills de especialista sob demanda (dados/analytics e IA/ML) foram adicionadas depois, a pedido do dono do OS, para decisões que exigem julgamento mais profundo do que o resto da cadeia oferece.
